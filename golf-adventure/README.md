# Golf Adventure

Fertiger Build (Vite/Three.js). **Braucht einen Webserver** (der Platz wird per `fetch` geladen) – über GitHub Pages oder lokal z. B. `npx serve` im Ordner `GAMES`.

Quellcode und Übergabe (`PROGRESS.md`) liegen im Entwicklungs-Repo `Games-Development`, Ordner `golf/`.
Neuen Build hier einspielen: dort `npm run build`, dann den Inhalt von `golf/dist/` nach `golf-adventure/` kopieren.
